# Qase Integration

## Overview

This project uses **Qase.io** as the Test Management System to simulate a real-world Software Quality Assurance workflow.

While GitHub is used to store complete testing documentation and supporting evidence, Qase is used to organize, manage, execute, and monitor manual test activities.

---

# Objectives

The objectives of integrating Qase into this portfolio are:

- Organize test cases into logical test suites
- Manage manual test execution
- Track execution progress
- Measure testing metrics
- Simulate industry-standard QA workflows
- Demonstrate experience using a Test Management System

---

# Testing Workflow

The testing workflow implemented in this project is:

```text
Requirement Analysis
        ↓
Application Analysis
        ↓
Test Planning
        ↓
Test Scenario Design
        ↓
Test Case Design
        ↓
Import Test Cases into Qase
        ↓
Create Test Suites
        ↓
Create Test Runs
        ↓
Execute Manual Tests
        ↓
Record Results
        ↓
Collect Evidence
        ↓
Report Defects
```
